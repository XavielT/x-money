# Muestras de bancos (solo en tu equipo)

Esta carpeta está en `.gitignore`: **nada de lo que pongas aquí se sube al repositorio**.

Si quieres evaluar cómo lee X Money tus avisos reales, guarda aquí capturas de tus avisos de consumo, depósitos y
facturas **con los datos sensibles tapados** (número de cuenta, nombre completo, cédula). Un script de evaluación
manual puede recorrer la carpeta; si está vacía no pasa nada y no falla nada: los tests del repositorio usan solo
muestras **sintéticas** inventadas y marcadas como tales.
